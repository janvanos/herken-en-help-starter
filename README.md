# Herken & Help – starterproject

Dit is je repo voor de hele module. Je werkt er vier weken in en levert er elke weekopdracht in in.

## Wat staat er al?

```
dataset/          hier komen je trainingsfoto's, één map per klasse (weekopdracht 1)
testset/          hier komen je 20 testfoto's (weekopdracht 1)
model/            hier komt je geëxporteerde model: model.json, metadata.json, weights.bin
js-oefeningen/    oefening 1 t/m 4 van de les JavaScript-basis (week 2)
testrapport.md    vul je in bij weekopdracht 1, en vul je aan bij weekopdracht 2
```

## Wat maak je zelf?

- **Week 1:** je foto's in `dataset` en `testset`, je model in `model`, en `testrapport.md`.
- **Week 2:** `index.html`, `script.js` en `style.css` voor je herkenpagina. Volg daarvoor het stappenplan van weekopdracht 2.

## Starten

1. Start je Docker-omgeving.
2. Open dit project via `localhost` in de browser.
3. Open bestanden **niet** door erop te dubbelklikken (`file://`). Dan mag de browser je model niet laden en werkt de webcam niet.
